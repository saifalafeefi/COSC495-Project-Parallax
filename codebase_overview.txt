SCRIPT DETAILS — ARPlaceCube.cs
  Location: Assets/Scripts/ARPlaceCube.cs
  Class:    ARPlaceCube : MonoBehaviour
  Purpose:  Places an object on a detected AR surface via touch or mouse click.
  Fields:
    [SerializeField] ARRaycastManager raycastManager — assigned in inspector
    bool isPlaced — cooldown flag to prevent rapid re-placement
  Logic:
    - On touch/mouse-down (with 0.25s cooldown):
      1. Raycasts against AR trackables using ARRaycastManager.
      2. If hit, instantiates raycastManager.raycastPrefab at hit pose.
      3. Starts coroutine to reset isPlaced after 0.25 seconds.
    - Supports both touch input (mobile) and mouse input (editor).
  Notes:
    - Uses the legacy Input class (Input.GetTouch / Input.GetMouseButtonDown),
      NOT the new Input System, despite the Input System package being installed.
    - raycastPrefab is set on the ARRaycastManager component (built-in field).
    - No object removal, scaling, or rotation logic yet.
